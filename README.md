# Kadali Dental Clinic Website

## 📋 Project Overview

**Kadali Dental Clinic** is a comprehensive dental care website for a premium dental clinic located in Mumbai, India. The website showcases various dental treatments, team information, patient testimonials, and provides multiple contact channels for potential patients.

### 🏥 Business Information
- **Clinic Name**: Kadali's Advanced Dental Care & Centre for Cosmetic Dentistry
- **Locations**: Andheri West & Colaba, Mumbai, India
- **Phone**: +91 981 920 1882
- **Email**: info@kadalidental.com
- **Website**: Professional dental clinic website

## 🚀 Features

### Core Functionality
- **Responsive Design**: Mobile-first approach with comprehensive breakpoints
- **Multi-page Structure**: 15+ dedicated pages for different services
- **Interactive Elements**: Sliders, testimonials, before-after galleries
- **Contact Integration**: Phone, WhatsApp, and contact form
- **SEO Optimized**: Meta tags, structured content, and semantic HTML

### Key Pages
1. **Home Page** (`index.html`) - Landing page with hero slider and service overview
2. **Team Page** (`Dentists.html`) - Doctor profiles and credentials
3. **Treatment Pages** - Individual pages for each dental service
4. **Testimonials** (`Testimonials.html`) - Patient reviews and video testimonials
5. **Before & After Gallery** (`before-after.html`) - Treatment results showcase
6. **Contact Page** (`contact-us.html`) - Contact form and clinic information
7. **Location & Tourism** - Clinic locations and dental tourism information

### Technical Features
- **Cross-browser Compatibility**: Works on all modern browsers
- **Mobile Responsive**: Optimized for all device sizes
- **Fast Loading**: Optimized images and efficient CSS
- **Accessibility**: Semantic HTML and ARIA labels
- **Interactive UI**: Hover effects, animations, and smooth transitions

## 🔧 Setup & Installation

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for development)

### Quick Start
1. **Clone or Download** the project files
2. **Open** `index.html` in a web browser
3. **Navigate** through the website to explore features

### Development Setup
1. **Local Server** (recommended):
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

2. **Access** the website at `http://localhost:8000`

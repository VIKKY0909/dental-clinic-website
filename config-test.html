🔧 Configuration Test

This page helps you verify that your API keys are properly configured for production deployment.

📋 Configuration Instructions

  1. Web3Forms Setup:
    • Go to web3forms.com
    • Sign up and get your access key
    • Replace YOUR_WEB3FORMS_ACCESS_KEY in config.js
  2. ImgBB Setup (Optional):
    • Go to api.imgbb.com
    • Get your free API key
    • Replace YOUR_IMGBB_API_KEY in config.js
    • Set ENABLED: true for image uploads
  3. Deployment:
    • For Vercel/Netlify: Use environment variables
    • For other hosts: Replace config.js with real keys
    • Never commit real keys to version control
